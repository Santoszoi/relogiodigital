# Digital Clock UI

Exercício visual de JavaScript para exibição de data e hora local.

## O que demonstra

- atualização da interface em tempo real;
- formatação localizada com `Intl.DateTimeFormat`;
- números tabulares para evitar deslocamento visual;
- elemento semântico `time`;
- layout responsivo.

## Rodando localmente

```bash
git clone https://github.com/Santoszoi/relogiodigital.git
cd relogiodigital
python -m http.server 8000
```

Abra `http://localhost:8000`.

HTML, CSS e JavaScript sem frameworks.
